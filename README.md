# desregulation.com.ar

Citizen dashboard of Argentina’s official monthly deregulation report (Unidad de Evaluación de Impacto).

Data for Agosto 2026 from [@fedesturze](https://x.com/fedesturze/status/2096922654028579217) and [Desregulación en Números](https://www.argentina.gob.ar/desregulacion/desregulacion-en-numeros).

Not an official government site.

## Local

```bash
python3 -m http.server 8766 --directory .
```

Open http://127.0.0.1:8766/
